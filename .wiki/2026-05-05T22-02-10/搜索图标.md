# 搜索图标

你记不住图标的名字。或者你知道大致的名字但不确定精确拼写。又或者你想看看某个分类下有哪些相关图标。`licon search` 就是为解决这些问题而生的。

它基于 **模糊搜索（fuzzy search）** 技术——你不必准确输入图标名，只要拼写相近、甚至只输入含义相关的词，它都能帮你找到匹配的图标。

## 一句话用法

```bash
licon search <查询词> [选项]
```

这是最常用的起步命令，也是 AI Agent 在不确定图标名称时的首选入口。如果你还没配置好 licon，请先阅读 [快速开始](快速开始.md)。

## 三种查询语法

`search` 支持三种查询模式，适应不同的搜索习惯。

### 单关键词搜索

最基础的形式，输入一个词即可：

```bash
licon search settings
```

输出按模糊匹配度排序，最相关的结果排在最前面：

```
[settings] 390 results:

settings
settings-2
calendar-cog
wrench
columns-3-cog
```

**工作原理**：`fuzzy.filter` 将你的输入与每个图标的 `searchText`（由图标名 + 分类名 + 标签拼接而成）进行模糊匹配，返回一个按匹配度降序排列的结果列表。

[来源](src/commands/search.ts#L55-L70)

### 逗号分隔的多搜索

用逗号同时搜多个关键词，每个关键词**独立**查询并输出各自的结果，结果之间用 `---` 分隔：

```bash
licon search settings,gear
```

输出：

```
[settings] 390 results:
settings
settings-2
calendar-cog
wrench
columns-3-cog
---
[gear] 815 results:
gear
cog
gear-icon
settings-2
wrench
```

这种模式适合**一次批量搜索多个不相关的方向**，例如同时了解"设置"和"齿轮"两个主题下各有什么图标。

**注意**：逗号前后不要有空格，或者确保空格被正确 trim。代码内部会用 `,` 分割后对每个关键词独立调用 `fuzzy.filter`。

[来源](src/commands/search.ts#L25-L53)

### 空格分隔的 AND 搜索

用空格分隔多个词，执行 **AND（与）逻辑**——结果必须同时匹配所有关键词：

```bash
licon search arrow left
```

这会找出既匹配 `arrow` 又匹配 `left` 的图标，例如 `arrow-left`、`arrow-left-from-line` 等。

**与逗号搜索的区别**：逗号是两次独立的搜索，输出两段结果；空格是一次搜索，但匹配条件更严格——每个候选图标必须同时包含所有关键词。代码层面，空格和逗号走的是同一分支逻辑，按对应分隔符切分后分别执行 `fuzzy.filter`。

[来源](src/commands/search.ts#L25-L28)

## 选项详解

### `-v`：显示分类与标签

默认情况下，`search` 只输出图标名称。加上 `-v`（`--verbose`）后，会在名称后面显示分类和标签信息：

```bash
licon search settings -v
```

输出：

```
[settings] 390 results:

settings [account] (settings,  gear, preferences, settings, tools, view)
settings-2 [account] (settings,  gear, preferences, settings, tools, view)
calendar-cog [account] (calendar, cog, gear, settings)
wrench [account] (maintenance, repair, settings, tool, wrench)
columns-3-cog [account] (columns,  gear, layout, settings)
```

格式为：`图标名 [分类] (标签)`。这对**快速判断某个图标是否符合你的需求场景**非常有帮助，也常用于 AI Agent 在搜索结果中做进一步筛选。

[来源](src/commands/search.ts#L37-L39)

### `-n`：限制结果数

默认返回 5 个结果。用 `-n`（`--limit`）可自定义数量：

```bash
licon search arrow -n 3
licon search arrow -n 20
```

命令行中的默认值定义在 `src/index.ts` 中：

```typescript
.option('-n, --limit <num>', 'Number of results to show (default: 5)', '5')
```

在 `searchCommand` 函数中，`limit` 取 `options.limit` 的值，如果未提供则默认为 `5`。最终通过 `.slice(0, limit)` 截取结果。

[来源](src/index.ts#L46) | [来源](src/commands/search.ts#L19)

## 幕后：两条核心逻辑

### `getIconList` 的缓存机制

每次搜索前，`searchCommand` 会调用 `getIconList(config)` 获取图标列表。这个函数做了两件事：

1. **从磁盘读取**：扫描 `config.iconsDir`（默认为 lucide 仓库的 `icons/` 目录）下的所有 `.json` 文件，解析每个图标的名称、分类和标签，拼接成 `searchText`。
2. **缓存结果**：将解析后的列表存储在模块级变量 `cachedIconList` 中。第二次及后续搜索**不再重新读取磁盘**，直接返回缓存。

```typescript
let cachedIconList: any[] | null = null;

function getIconList(config: Config): any[] {
  if (cachedIconList) {
    return cachedIconList;  // 命中缓存，跳过文件读取
  }
  // ...读取并解析所有 .json 文件...
  cachedIconList = iconList;
  return cachedIconList;
}
```

如果你更新了 lucide 仓库（例如通过 `licon upgrade`），可以调用 `clearSearchCache()` 清除缓存，确保下次搜索使用最新数据。

[来源](src/commands/search.ts#L3-L17) | [来源](src/commands/search.ts#L73-L75)

### `fuzzy.filter` 的匹配逻辑

`fuzzy` 库的核心函数 `fuzzy.filter` 接受三个参数：

- **查询词**：用户输入的关键词
- **候选列表**：`getIconList` 返回的图标数组
- **`extract` 函数**：告诉 fuzzy 从每个候选中提取哪个字段来做匹配

```typescript
fuzzy.filter(query, iconList, {
  extract: (item) => item.searchText
})
```

`searchText` 是 "图标名 + 分类字符串 + 标签字符串" 的拼接产物，所以搜索 "settings" 时，不仅会匹配名为 `settings` 的图标，还会匹配分类或标签中包含 "settings" 的图标（例如 `wrench` 的标签包含 "settings"）。

fuzzy 会对每个候选计算一个匹配分数，然后**按分数从高到低排序**。`searchCommand` 拿到排序后的结果后，用 `.slice(0, limit)` 截取前 N 个输出。

[来源](src/commands/search.ts#L30-L33) | [来源](src/commands/search.ts#L58-L62)

## 完整输出示例

### 单关键词 + verbose

```bash
licon search heart -v -n 3
```

```
[heart] 415 results:

heart [medical] (cardiology, health, heart, heart rate, love, pulse)
heart-pulse [medical] (cardiogram, ecg, ekg, heart, heart rate, pulse)
heart-off [medical] (heart, off, pulse, unhealth, unhealthy)
```

### 逗号多搜索 + 限制数量

```bash
licon search sun,moon -n 2
```

```
[sun] 63 results:
sun
sun-moon
---
[moon] 39 results:
moon
sun-moon
```

### 空格 AND 搜索

```bash
licon search file text -n 3
```

```
[file text] 276 results:
file-text
file-text-icon
file-type
```
