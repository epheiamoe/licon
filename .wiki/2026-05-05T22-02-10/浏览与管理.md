## 发现图标库

你能想象一个拥有数千个精美图标的**整个仓库**装在你的电脑里吗？`licon` 的四个管理命令就是帮你探索这个宝藏的钥匙——先看看库有多大、分类有哪些，再精准定位你需要的图标。

---

### 📋 `licon list` — 一览全貌

这是你探索图标库的起点。执行 `licon list`，终端会打印两样东西：**图标总数**和**每个图标的名称及其分类**。

```
$ licon list
Total icons: 1649

alarm-clock [devices]
alarm-clock-off [devices]
book [education]
book-a [education]
book-check [education]
...
```

输出格式为 `图标名 [分类]`，如果图标还有标签（tags），会额外显示 `(tags: ...)`。

它的实现逻辑很直接：读取本地 Lucide 仓库中 `icons/` 目录下的所有 `.json` 文件，每个 `.json` 文件对应一个图标。解析文件中的 `categories` 和 `tags` 字段，逐行打印。

[来源](src/commands/list.ts#L1-L30)

---

### 🗂️ `licon cat <分类>` — 按分类筛选

当你知道要找哪类图标时，`licon cat` 比 `licon list` 高效得多。它接受一个分类名称作为参数，**只输出属于该分类的图标**。

```
$ licon cat animals
Category "animals" (11 icons):

bee, bug, chicken, duck, fish, ladybug, rabbit, rat, shell, snail, turtle
```

如果输入的分类不存在，它会友好地提示你：

```
$ licon cat nonexistent
No icons found in category "nonexistent"
Use "licon categories" to see available categories.
```

内部逻辑也很直观：遍历所有图标的 JSON 元数据，检查 `categories` 数组是否包含你指定的分类名，匹配则加入结果列表。

[来源](src/commands/cat.ts#L1-L32)

---

### 📂 `licon categories` — 查看所有分类

`licon cat` 需要你知道分类名才能用。不知道有哪些分类？那就用 `licon categories`。

```
$ licon categories
Available categories:
  - accessibility
  - animals
  - arrows
  - audio-video
  - buildings
  - business
  - chemistry
  - communication
  - ...
```

这个命令不是去读取每个图标的元数据来汇总分类，而是**直接读取本地 Lucide 仓库中 `categories/` 目录里所有的 `.json` 文件**——Lucide 官方已经为每个分类准备了独立的描述文件，文件名就是分类名。

这是最轻量的方式，不需要遍历成千上万个图标。

[来源](src/index.ts#L96-L113)

---

### ⬆️ `licon upgrade` — 更新本地仓库

图标库隔段时间就会新增图标。`licon upgrade` 帮你把本地 Lucide 仓库更新到最新版本。

执行时它会：

1. 检查你是否已配置仓库路径（否则提示先跑 `licon setup`）
2. 进入仓库目录执行 `git pull`
3. 打印成功或失败信息

```
$ licon upgrade
Updating lucide repository at: /home/user/lucide

Already up to date.

✅ Lucide repository updated successfully!
```

注意：这**不是**更新 `licon` 工具本身，而是更新它依赖的 Lucide 图标仓库。如果 `git pull` 失败（例如网络问题或仓库被删除），命令会以非零状态码退出。

[来源](src/commands/upgrade.ts#L1-L32)

---

### 命令对比速查

| 命令 | 作用 | 数据来源 | 适合场景 |
|------|------|----------|----------|
| `licon list` | 列出所有图标及分类 | `icons/*.json` | 了解图标库全貌 |
| `licon cat <分类>` | 按分类筛选图标 | `icons/*.json` 中的 `categories` 字段 | 知道分类名，想看该分类图标 |
| `licon categories` | 列出所有可用分类 | `categories/*.json`（目录列表） | 不知道有哪些分类 |
| `licon upgrade` | 更新本地 Lucide 仓库 | 执行 `git pull` | 图标库有更新时 |
