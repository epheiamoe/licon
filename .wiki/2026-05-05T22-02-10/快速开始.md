只需要 5 分钟，你就能从零开始获取第一个 Lucide 图标。下面是完整流程。

---

## 安装

licon 发布在 npm 上，全局安装即可使用：

```bash
npm install -g @epheiamoe/licon
```

安装完成后，验证是否成功：

```bash
licon --version
```

如果输出版本号（如 `1.0.1`），说明安装成功。licon 的入口在 `dist/index.js`，通过 `package.json` 的 `bin` 字段注册为全局命令。

[来源](package.json#L7-L9)

---

## 克隆 Lucide 图标库

licon 读取的是本地 Lucide 图标仓库的 **SVG 文件和元数据**，所以需要先将 [lucide](https://github.com/lucide-icons/lucide) 克隆到本地：

```bash
git clone https://github.com/lucide-icons/lucide.git ~/projects/lucide
```

> 你也可以克隆到其他路径，后续 `licon setup` 时会要求指定路径。

克隆完成后，确认目录下包含 `icons/` 和 `categories/` 这两个文件夹——这是 `isValidRepo()` 函数检查的依据。

[来源](src/config.ts#L38-L40)

---

## 配置（关键前提）

**这是所有命令使用前必须完成的一步。** licon 需要一个配置文件来记住你的 Lucide 仓库位置。

运行：

```bash
licon setup
```

你会看到交互式提示：

```
🔧 Lucide CLI Setup

Please enter the path to your local lucide repository.
(Leave empty to use default: ~/projects/lucide or clone fresh)

Lucide repository path:
```

输入刚才克隆的路径（如 `C:\Users\你的用户名\projects\lucide` 或 `~/projects/lucide`），回车确认。

如果路径有效，会看到：

```
✅ Configuration saved to: C:\Users\你的用户名\.licon.json
   Repository: /path/to/lucide
```

配置文件 `~/.licon.json` 的内容类似这样：

```json
{
  "repoPath": "/path/to/lucide",
  "iconsDir": "/path/to/lucide/icons"
}
```

如果配置不存在就运行其他命令，licon 会拒绝执行并提示：

```
❌ Configuration not found. Please run: licon setup
```

这是由 `ensureSetup()` 函数实现的——它检查配置文件是否存在，不存在就拦截并输出提示：

[来源](src/commands/setup.ts#L67-L72)

## 搜索图标

有了配置，就可以搜索了。试试搜索 `arrow` 相关的图标：

```bash
licon search arrow
```

输出示例：

```
[arrow] 24 results:

arrow-big-down
arrow-big-up
arrow-down
arrow-down-0-1
arrow-down-1-0
```

默认显示前 5 个结果，可以用 `-n` 指定数量，用 `-v` 显示分类和标签详情：

```bash
licon search arrow -n 10 -v
```

`search` 命令使用 `fuzzy` 库进行模糊匹配，不仅匹配图标名称，还会搜索分类和标签文字。

[来源](src/commands/search.ts#L30-L39)

---

## 获取 SVG

找到想要的图标名称后，用 `get` 命令获取它的 SVG 代码：

```bash
licon get arrow-right
```

输出：

```svg
<!-- arrow-right [arrows] -->
<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <path d="M5 12h14"/>
  <path d="m12 5 7 7-7 7"/>
</svg>
```

可以一次获取多个图标，用空格分隔：

```bash
licon get arrow-right search user
```

各图标之间用 `---` 分隔。

如果需要 JSON 格式（方便程序解析），加 `--format json`：

```bash
licon get arrow-right --format json
```

[来源](src/commands/get.ts#L44-L56)

## 交互模式：不用记命令

如果不想记忆任何命令，直接运行：

```bash
licon
```

licon 检测到没有参数时，会自动进入交互模式。如果是首次运行且未配置，会先引导你完成 `setup`。

[来源](src/index.ts#L96-L104)

交互模式下，你可以用方向键浏览、输入关键词模糊搜索、按分类浏览、预览 SVG——全程无需记忆任何命令。

详见 [交互模式](交互模式.md)。
