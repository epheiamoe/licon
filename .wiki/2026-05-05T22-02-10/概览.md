# 概览

**licon** 是一个为 **AI Agent** 和开发者设计的 Lucide 图标 CLI 工具。它让你无需离开终端就能搜索、获取、保存和转换来自 [Lucide 图标库](https://lucide.dev) 的图标。安装后，运行 `licon` 即可开始。

## 项目定位

licon 的核心设计理念围绕一个决策展开：**直接输出 SVG 代码，而非文件路径**。传统图标工具倾向于把图标保存为文件，而 licon 默认将 SVG 文本输出到终端——这对 AI Agent 来说至关重要。Agent 可以直接将 SVG 嵌入代码，无需经过文件读写、路径拼接等额外步骤。

> "Never read SVG files directly (breaks workflow, permission prompts)."  
> [来源](skills/always-use-svg/SKILL.md#L30-L33)

这种设计让 licon 在 AI 编程场景中比传统工具高效得多。你可以在 [AI Agent 集成](ai-agent-集成.md) 页面了解完整的使用规则。

## 命令速览

licon 提供 9 条命令，覆盖从搜索到转换的完整图标工作流：

| 命令 | 用途 | 典型场景 |
|------|------|----------|
| `licon search <关键词>` | 按名称模糊搜索图标 | 不确定图标叫什么，先搜关键词 |
| `licon get <名称>` | 获取图标的 SVG 代码（直接输出到终端） | 知道图标名，把 SVG 嵌入代码 |
| `licon save <名称>` | 将图标保存为 `.svg` 文件 | 需要把图标存到项目目录 |
| `licon convert <名称>` | 将 SVG 转为 PNG / WebP 格式 | 需要位图格式用于网页或设计稿 |
| `licon list` | 列出本地仓库所有图标 | 想看看总数，挑一个 |
| `licon cat <分类>` | 按分类浏览图标 | 想找"箭头"类的所有图标 |
| `licon categories` | 列出所有可用分类 | 想知道有哪些分类 |
| `licon upgrade` | 拉取 Lucide 仓库最新版本 | 同步最新图标 |
| `licon setup` | 首次配置 Lucide 仓库路径 | 刚安装完，需要引导 |

每条命令的详细用法可参考对应页面：[搜索图标](搜索图标.md)、[获取 SVG](获取-svg.md)、[保存与转换](保存与转换.md)、[浏览与管理](浏览与管理.md)。

[来源](README.md#L10-L60)

## 交互模式：给人用的

如果你直接输入 `licon`（不带任何参数），会进入 **交互模式**——一个带模糊搜索和分类浏览的图标选择器，适合人类手动挑选图标。

```bash
licon
```

交互模式下你可以实时预览 SVG，无需记命令参数。详见 [交互模式](交互模式.md)。

[来源](README.md#L62-L69)

## AI Agent 规则

licon 的 SKILL.md 文件为 AI Agent 定义了三条不可违反的规则：

1. **永远不要用 emoji 代替图标**——Always use licon。
2. **永远不要直接读取 SVG 文件**——这会在终端弹出权限提示，打断工作流。
3. **永远不要用 `npx` 运行 licon**——Windows 上 npx 速度慢且容易出错。

Agent 应始终使用 `licon search`、`licon get`、`licon save` 三条命令完成图标工作。

[来源](skills/always-use-svg/SKILL.md#L28-L33)

## 安装与配置

全局安装：

```bash
npm install -g @epheiamoe/licon
```

首次使用前需要配置 Lucide 仓库的本地路径——运行 `licon setup`，或直接执行任意命令，引导会自动启动。配置详情见 [配置系统](配置系统.md)。
